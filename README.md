# Gesture Flow

**Gesture Flow** lets you control your Mac with hand gestures and voice. Adjust volume and brightness, toggle playback, and run hands‑free commands—all through the camera and microphone.

## Highlights

- **Touchless control**: Change volume and brightness with simple hand gestures.
- **Voice commands**: Speak to control media, system volume, and brightness.
- **Wake word mode**: Add a custom wake word for extra safety.
- **HUD + status indicators**: Real‑time on‑screen feedback.
- **Instant toggle**: Quickly enable/disable gestures.
- **Sparkle updates**: In‑app updates with automatic checks.

## Getting Started

1. Download the latest DMG.
2. Open the DMG and drag **Gesture Flow** into **Applications**.
3. Launch the app.
4. Grant permissions when prompted:
   - **Camera** (for hand tracking)
   - **Microphone** (for voice commands)
   - **Accessibility** (to control system settings)

## Gestures

- **Brightness**: Adjust with left‑hand gestures.
- **Volume**: Adjust with right‑hand gestures.
- **Status indicators** show live feedback for tracking and system changes.

## Voice Commands

Always available (no wake word):
- "Enable gestures" / "Disable gestures"
- "Turn on gestures" / "Turn off gestures"
- "Start gestures" / "Stop gestures"

Protected (requires wake word if enabled):
- "Play" / "Pause"
- "Mute" / "Unmute"
- "Set volume to 50%"
- "Set brightness to 70%"

## Settings

- **Appearance**
  - Show status indicators
  - Show master toggle
  - Show debug console

- **Voice Control**
  - Set a custom wake word
  - Require "Hey" or "Hi" prefix

- **Updates**
